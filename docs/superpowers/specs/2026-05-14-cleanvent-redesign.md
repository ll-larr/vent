# Clean Vent — Редизайн и рефакторинг сайта

**Дата:** 2026-05-14  
**Статус:** Одобрено пользователем

---

## Контекст

Сайт компании по чистке вентиляционных систем. Полный редизайн с нуля: новый дизайн, новая структура, форма заявок с интеграцией Google Sheets, интерактивный калькулятор стоимости.

---

## Целевая аудитория

**Основные клиенты:** B2B — общепит (рестораны, кафе, столовые, фастфуд), офисы, склады, мелкие производства.  
**Крупные клиенты** (арены, заводы) — не отказываем, но не основной фокус сайта.

---

## Дизайн

**Палитра:** тёмно-зелёный (`#1e5c32`) + белый + светло-зелёный фон (`#f7faf7`).  
**Характер:** свежий, чистый, ассоциируется с чистым воздухом. Профессиональный, но не скучный.  
**Шрифт:** Onest (уже в проекте). Обеспечить контраст — шрифт не должен сливаться с фоном.  
**Стек:**
| Слой | Технология | Роль |
|------|-----------|------|
| Фреймворк | Next.js 14 App Router | Роутинг, SSR, API routes |
| Язык | TypeScript | Типобезопасность, особенно в логике калькулятора и API |
| Стили | Tailwind CSS | Утилитарный CSS, быстрая разработка |
| Компоненты | shadcn/ui | Копи-паст компоненты (чекбоксы, инпуты, карточки) — не зависимость |
| Формы | React Hook Form + Zod | Валидация полей формы и API-схем |
| Состояние | React useState / useReducer | Калькулятор — локальное состояние, без Redux/Zustand |

Sass удаляется полностью — стили переезжают на Tailwind. Глобальные токены (цвета, радиусы) переносятся в `tailwind.config.ts`.  
**При реализации:** использовать скилы `frontend-design` и `ui-ux-pro-max`.

## Калькулятор стоимости

### Принцип работы

1. Клиент выбирает **пакет** по типу объекта
2. Видит **состав пакета** — список услуг с чекбоксами (можно убрать или добавить)
3. Вводит **площадь помещения (м²)** с подсказкой «площадь вашего ресторана, офиса или объекта»
4. Видит **ориентировочную цену** (диапазон «от X ₽») — обновляется в реальном времени
5. Нажимает **«Оставить заявку»** — форма предзаполняется выбранными услугами

### Пакеты

| Пакет | Услуги по умолчанию |
|-------|---------------------|
| 🍽 Общепит | Чистка вентиляции (от жира) + чистка вытяжек (зонты) |
| 🏢 Офис | Чистка вентиляции (от пыли) |
| 🏭 Производство/Склад | Чистка вентиляции (от пыли) + дезинфекция |
| ⚙️ Своё | Пустой список, клиент собирает сам |

### Ценообразование (от м²)

Цены приблизительные — используем коэффициент пересчёта м² → пог.м.  
Показываем диапазон «от N ₽» с пометкой «Точная стоимость — после осмотра».

| Услуга | Ед. | Цена |
|--------|-----|------|
| Вентиляция от пыли | м² | ~90–135 ₽/пог.м → коэффициент 0.3 пог.м/м² |
| Вентиляция от жира | м² | ~270–360 ₽/пог.м → коэффициент 0.3 |
| Чистка вытяжки (зонт) | шт. | от 1 800 ₽ фикс |
| Дезинфекция | м² | ~27 ₽/пог.м → коэффициент 0.3 |

Логика калькулятора реализуется на клиентской стороне (React state, без API).

## Форма заявки

### Поля

| Поле | Тип | Обязательное |
|------|-----|------|
| Имя | text | да |
| Телефон | tel | да |
| Тип объекта | text | да — placeholder: «Ресторан "Доминос пицца"» |
| Какие услуги нужны | checkboxes | нет (предзаполняется из калькулятора) |
| Комментарий | textarea | нет |

### Валидация

- Телефон: российский формат, проверка на клиенте
- Обязательные поля подсвечиваются при попытке отправить пустыми

### Услуги — чекбоксы

- Чистка вентиляции (от пыли)
- Чистка вентиляции (от жира)
- Чистка вытяжек
- Чистка труб
- Дезинфекция
- Чистка резервуаров
- Диагностика/осмотр

## Интеграция Google Sheets

### Архитектура

`Форма → POST /api/submit → Google Sheets API → строка в таблице`

### Реализация

- Next.js API Route: `src/app/api/submit/route.js`
- Google Service Account (JSON-ключ в `.env.local`, не в git)
- Библиотека: `googleapis`

### Столбцы таблицы

`Дата/время | Имя | Телефон | Тип объекта | Услуги | Комментарий | Источник`

### Переменные окружения

```
GOOGLE_SERVICE_ACCOUNT_EMAIL=...
GOOGLE_PRIVATE_KEY=...
GOOGLE_SHEET_ID=...
```

### Будущее: Telegram

Добавить в `route.js` вызов Telegram Bot API после записи в Sheets. Потребует `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.

## Скролл-анимации

Существующий `useScrollAnim` хук переписать под TypeScript. Логика остаётся — `IntersectionObserver` + `data-anim` атрибут + класс `visible`. Анимация `fade-up` переносится из Sass-миксина в Tailwind-классы (`opacity-0 translate-y-6 transition-all → opacity-100 translate-y-0`).
