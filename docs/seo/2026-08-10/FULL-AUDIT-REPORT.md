# SEO-аудит vent-final.vercel.app

**Дата:** 10.08.2026
**Объект:** https://vent-final.vercel.app (после редизайна «скролл-история»)

> **Апдейт того же дня.** Аудит снят до появления домена. Вечером 10.08 компания купила
> `vent-clean.ru` (reg.ru, DNS `ns1.reg.ru`), домен делегирован, сертификат выпущен, сайт
> переехал: апекс — канонический адрес, `www` и `vent-final.vercel.app` отдают 308 на него,
> бренд переименован в **Vent Clean**. Критичная проблема №1 закрыта. Проблемы №2 (нет
> измерений), №3 (нет адреса), №4 (тонкие статьи) и №5 (ноль упоминаний) — в силе.
**Тип бизнеса:** локальный сервис без клиентского зала (service-area business), B2B —
промышленная чистка вентиляции для HoReCa, офисов, складов. Москва + 100 км.
**Метод:** обход всех внутренних ссылок (15 страниц, 500-страничный лимит не достигнут),
разбор HTML каждой страницы, проверка `robots.txt` / `sitemap.xml` / `llms.txt`, заголовков
ответа, JSON-LD, лабораторные Core Web Vitals в Chromium на десктопе и на 390 px,
проверка доступа шести краулеров по User-Agent.

Сайт технически здоров и очень быстр. Всё, что мешает, — не код: нет домена, нет ни одной
системы измерения и нет адреса, без которого локальная выдача не работает.

## Пять критичных проблем

1. **Домена нет.** `vent.team` — NXDOMAIN на дату аудита, к проекту Vercel не привязан ни
   один домен (`vercel domains ls` → 0). Сайт живёт на `vent-final.vercel.app`. Всё, что
   успеет проиндексироваться, придётся переносить 301-ми, часть сигналов теряется. Почта
   `hello@vent.team` тоже не работает — форма собирает лиды, ответить с этого адреса нечем.
2. **Измерений ноль.** Нет Google Search Console, нет Яндекс.Вебмастера, нет Метрики и GA4.
   Проверить, что происходит в выдаче, физически нечем; данные начнут копиться только со
   дня подключения, поэтому это дороже откладывать, чем сделать.
3. **NAP неполный.** В `LocalBusiness` нет `streetAddress` и `postalCode`. Без адреса не
   создать карточку в Google Business Profile и Яндекс.Бизнесе, а для локального сервиса
   это основной канал — важнее, чем позиции в органике.
4. **Контент статей тонкий.** 495–617 слов против ~1000+ у конкурента (`ventsistema.ru`).
   Редизайн перенёс дизайнерские тексты и статьи стали короче, чем были до него.
5. **Нет ни одной внешней ссылки и ни одного упоминания бренда.** Домен новый, история
   нулевая. Ни органика, ни AI-ответы не имеют оснований цитировать сайт.

## Пять быстрых побед

1. Зарегистрировать домен и привязать к проекту, переключить `NEXT_PUBLIC_SITE_URL`,
   поставить 301 с `vercel.app`. Полчаса работы, снимает проблему №1.
2. Подключить GSC + Яндекс.Вебмастер + Метрику. Верификация — один мета-тег или файл.
3. Добавить перелинковку из статей на страницы услуг: сейчас статья ссылается только на
   калькулятор и соседние статьи, а коммерческие страницы получают ссылки только из футера.
4. Заполнить `sameAs` в `LocalBusiness`, когда появятся реальные Telegram/WhatsApp/карточки.
5. Поставить по одному кадру на страницу услуги — фотографии уже лежат в `public/images`,
   а страницы по 1000–1270 слов идут вообще без единой картинки.

## Технический SEO — 80

**Что работает.**

- Все 15 страниц отвечают 200, битых внутренних ссылок нет.
- Канонические адреса самоссылочные и совпадают с реальным хостом на всех страницах.
- `robots.txt` открывает сайт, закрывает `/api/`, указывает на sitemap.
- `sitemap.xml` — 14 URL, `lastmod` датирован редизайном, `/privacy` исключён намеренно
  (у него `noindex, follow` в мете, и он остаётся доступным для обхода).
- Заголовки безопасности на месте: HSTS `max-age=63072000; includeSubDomains`, `nosniff`,
  `X-Frame-Options: DENY`, `Referrer-Policy: strict-origin-when-cross-origin`,
  `Permissions-Policy` с выключенными камерой, микрофоном и геолокацией.
- HTTPS, gzip, `x-vercel-cache: HIT`, `lang="ru"`, корректный viewport на всех страницах.
- Удалённая услуга отдаёт 308 на `/uslugi` — постоянный редирект, для поиска равнозначен 301.

**Проблемы.**

| Severity | Проблема | Что делать |
|---|---|---|
| Critical | Канонический хост — превью-домен Vercel | Зарегистрировать `vent.team`, привязать к проекту, сменить `NEXT_PUBLIC_SITE_URL`, 301 с vercel.app |
| Medium | Нет верификации в GSC и Яндекс.Вебмастере | Добавить мета-теги верификации в `metadata.verification` |
| Low | Нет `X-Robots-Tag` на PDF в `/files` | Решить, нужен ли прайс в индексе; если нет — закрыть заголовком |

## On-page — 82

- Title: 20–59 символов, ни один не обрезается в выдаче.
- Description: 120–167 символов; `/contacts` был 167 → сокращён до 152 в этом же прогоне.
- Ровно один H1 на страницу, иерархия H2/H3 не рвётся.
- Alt проставлен у всех 16 изображений главной и у всех иллюстраций статей; декоративные
  идут с пустым alt осознанно.
- Внутренних ссылок: 3–11 на страницу.

**Главная проблема on-page — перелинковка.** Коммерческие страницы (`/uslugi/*`) получают
входящие ссылки почти только из футера. Статьи, которые и будут собирать поисковый трафик,
ведут на калькулятор и друг на друга, но не на услуги — то есть трафик приходит на
информационный запрос и не переходит в коммерческий.

## Микроразметка — 78

**Есть:** `LocalBusiness` (site-wide, с `@id`), `Service` ×4 на главной, `FAQPage` на
главной, калькуляторе, всех страницах услуг и всех статьях, `Article` + `BreadcrumbList` на
статьях, `WebSite` (добавлен в этом прогоне). Ошибок парсинга JSON-LD нет.

**Нет:** `streetAddress`/`postalCode`, `sameAs` (нет подтверждённых профилей),
`aggregateRating` (намеренно), `HowTo` — хотя секция 02 это буквально пошаговая инструкция
из шести шагов с ценами, `ImageObject` для фото «до/после», `Offer` с конкретными ценами
на страницах услуг.

LCP-элемент — H1 героя, то есть текст, а не картинка: заголовок появляется сразу и не ждёт
фото. Сдвигов макета нет ни одного — все изображения идут через `next/image` с заданными
пропорциями. Сторонних скриптов нет вообще (аналитики тоже нет — см. критичную проблему №2).

Полевых данных (CrUX) нет: домен новый, трафика недостаточно. PageSpeed Insights API на
момент аудита ответил `Quota exceeded` для анонимных запросов — лабораторные цифры выше
получены собственным прогоном.
