# Анализ sitemap.xml

**Дата:** 10.08.2026 · **Адрес:** https://vent-final.vercel.app/sitemap.xml
**Источник:** `src/app/sitemap.ts` — генерируется Next.js из реестров `SERVICE_PAGES` и
`ARTICLES`, то есть не может разойтись с реальным набором страниц.

## Формат — валиден

| Проверка | Результат |
|---|---|
| XML-декларация | есть |
| Пространство имён `sitemaps.org/schemas/sitemap/0.9` | есть |
| Число URL | 14 (лимит 50 000) |
| Размер | 2.4 КБ (лимит 50 МБ) |
| Индексный sitemap | не нужен при таком объёме |
| Отдаётся из `robots.txt` | да, абсолютным адресом |
| Все URL абсолютные и совпадают с каноническими | да |
| Все URL отвечают 200 | да, проверено обходом |
| Редиректы и 404 внутри карты | нет |

## Покрытие

| В карте | Не в карте | Комментарий |
|---|---|---|
| `/` | — | приоритет 1.0, weekly |
| `/calculator`, `/contacts` | — | 0.8 / 0.6, monthly |
| `/uslugi` + 4 страницы услуг | — | 0.9 хабу, 0.8 страницам, monthly |
| `/blog` + 5 статей | — | 0.6, weekly / yearly |
| — | `/privacy` | правильно: страница `noindex, follow` |
| — | `/uslugi/dezinfekciya` | правильно: удалена, отдаёт 308 на хаб |

Обход внутренних ссылок нашёл ровно те же 14 индексируемых страниц плюс `/privacy`.
Сирот нет, страниц вне карты нет.

## Значения полей

- **lastmod** — `2026-08-10` у всех URL. Дата настоящая: редизайн переписал каждую
  страницу. Важно, что она не берётся из `new Date()`: карта, которая каждый день
  сообщает «изменено сегодня», обесценивает поле, и поисковики перестают на него смотреть.
  Даты живут константами в `sitemap.ts` и правятся руками при реальной правке контента.
- **priority** — 1.0 / 0.9 / 0.8 / 0.6, расставлены по коммерческой ценности. Поле
  давно почти не влияет на обход, но и вреда не несёт.
- **changefreq** — weekly у главной и блога, monthly у услуг, yearly у статей. Тоже
  подсказка, а не директива.

## Чего нет

| Расширение | Нужно ли | Комментарий |
|---|---|---|
| `image:image` | опционально | На сайте 40+ реальных фото «до/после» — это именно тот контент, ради которого стоит подавать картинки отдельно. Даст шанс на трафик из поиска по картинкам |
| `video:video` | нет | видео на сайте нет |
| `xhtml:link` (hreflang) | нет | сайт одноязычный, `lang="ru"` |
| `news:news` | нет | не новостной ресурс |

## Что делать

1. **После регистрации домена** карта перестроится сама (адреса берутся из `SITE_URL`), но
   старую версию на `vercel.app` нужно будет закрыть 301-м вместе с остальными адресами.
2. **Подать карту в GSC и Яндекс.Вебмастер** — сейчас она никуда не отправлена, и это
   единственный способ увидеть, что именно поисковик принял в индекс.
3. **Рассмотреть image-sitemap**, когда заказчик заменит сток в статьях на свои снимки:
   фотоотчёты «до/после» — редкий контент в этой нише.
