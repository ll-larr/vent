# Google API — что удалось и что нет

**Дата:** 10.08.2026 · **Объект:** https://vent-final.vercel.app

Задача этого блока — подтянуть **полевые** данные Google: Core Web Vitals из CrUX,
статус индексации и запросы из Search Console, органический трафик из GA4.

## Статус доступов

| Источник | Доступ | Что это значит |
|---|---|---|
| Search Console (Search Analytics, URL Inspection) | **нет** | Сайт не верифицирован ни в одном ресурсе GSC. Данных о показах, кликах, CTR и позициях не существует |
| GA4 | **нет** | Аналитика на сайте не установлена вообще — ни GA4, ни Метрики. Ноль сторонних скриптов подтверждено измерением |
| CrUX (полевые CWV) | **нет данных** | Домен новый, порога трафика для попадания в отчёт нет |
| PageSpeed Insights v5 | **квота исчерпана** | Анонимные запросы вернули `Quota exceeded for quota metric 'Queries'`. Нужен API-ключ либо повтор позже |
| Indexing API | **нет** | Требует сервисный аккаунт и верифицированный ресурс |

Ни одного файла с учётными данными Google в окружении нет, переменных вида
`GOOGLE_*_API_KEY` тоже. Поэтому раздел закрыт лабораторными измерениями.

## Лабораторные Core Web Vitals (замена полевым)

Chromium, реальный прод на Vercel edge:

| Метрика | Десктоп | Мобайл | Порог «хорошо» |
|---|---:|---:|---|
| LCP | 180 мс | 136 мс | ≤ 2500 мс |
| CLS | 0 | 0 | ≤ 0.1 |
| TTFB | 60 мс | 61 мс | ≤ 800 мс |
| Взаимодействия (клик по FAQ, смена таба объектов) | < 16 мс | < 16 мс | INP ≤ 200 мс |

LCP-элемент — H1 героя (текст), поэтому первый экран не ждёт загрузки фотографии.
Сдвигов макета не зафиксировано ни одного: изображения идут через `next/image` с
фиксированными пропорциями, шрифты — через `next/font` с `display: swap` и метрическим
фолбэком.

Лабораторные цифры не заменяют полевые: они сняты с прогретого кэша и быстрого канала.
Но запас до порогов такой, что провал в поле маловероятен.

## Что подключить (по порядку)

1. **Домен.** Верифицировать превью-адрес Vercel в GSC можно, но вся история привяжется к
   адресу, который вы собираетесь бросить. Сначала домен.
2. **Search Console.** Верификация мета-тегом — в `metadata.verification.google` в
   `src/app/layout.tsx`. Сразу подать `sitemap.xml`.
3. **Яндекс.Вебмастер.** Для этого бизнеса Яндекс важнее Google: аудитория — московский
   B2B. Верификация там же, `metadata.verification.yandex`.
4. **Яндекс.Метрика** (и GA4, если нужен). Метрика даёт вебвизор и карту скроллов — на
   лендинге-истории это единственный способ увидеть, докручивают ли до калькулятора.
5. **PageSpeed Insights с API-ключом** — для регулярных замеров без квоты.

Через 28 дней после подключения GSC появятся первые данные по запросам, через ~28 дней
после набора трафика — CrUX. До этого любые утверждения о позициях будут догадками.
